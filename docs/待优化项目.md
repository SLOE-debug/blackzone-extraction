# 大锤普攻智能朝向与肉鸽战斗手感重构

## 一、任务目标

重构大锤普通攻击的自动瞄准、目标维持、人物转向和移动控制，使玩家能够：

1. 向任意方向移动，同时自动攻击周围最有价值的怪群；
2. 向后撤退时，人物仍能转身攻击后方追击的怪物；
3. 按住攻击后稳定连续攻击，不因移动方向变化频繁丢失目标；
4. 每次挥击优先覆盖更多怪物，而不是机械攻击最近单体；
5. 保留大锤的重量、前摇和攻击承诺，但不能让玩家感觉角色不听指令。

核心控制契约：

```text
左摇杆只决定移动方向。
自动攻击系统决定攻击方向。
前摇阶段允许人物快速转向。
锤头接触阶段基本锁定攻击方向。
```

---

# 二、当前问题

当前实现存在以下错误规则：

1. 有移动输入时，自动锁敌只搜索移动方向左右 70°。
2. 玩家向怪物反方向撤退时，怪物会被扇区过滤。
3. 找不到目标后，攻击方向回退为当前移动方向。
4. 恢复阶段后半会主动释放自动锁定目标。
5. 目标选择以单体目标为核心，没有考虑一锤能够覆盖多少怪物。

因此出现：

```text
玩家向左下撤退
→ 右上怪物不在移动方向扇区
→ 自动目标查询失败
→ 攻击方向回退左下
→ 人物朝左下挥空
```

# 六、挥击方向评分算法

## 6.1 候选方向

每次开始新攻击或进入下一段连击预输入窗口时执行一次，不要每帧执行。

采样 24 个整圆方向：

```ts
const DIRECTION_SAMPLE_COUNT = 24;
```

即每 15°采样一个方向。

额外加入以下精确方向，避免固定采样误差：

```text
当前稳定目标方向
距离最近目标方向
最高威胁目标方向
人物当前朝向
上一击攻击方向
```

候选方向去重后进行评分。

## 6.2 每个方向的覆盖检测

对每个候选方向，检查搜索半径内所有存活怪物。

怪物满足以下条件时，计入该方向预计命中：

```ts
distance <= attackReach + monsterRadius

alignment >= Math.cos(attackArcRadians * 0.5)
```

攻击范围和攻击弧度必须复用真实大锤攻击定义，不得创建与实际伤害判定不一致的隐藏范围。

## 6.3 第一版评分公式

第一版先实现稳定、可调试的简单评分：

```ts
score =
    expectedHitCount * 10
  + closeThreatCount * 4
  + preferredTargetIncluded * 8
  + eliteTargetCount * 6
  + headingContinuityScore
  - rotationCost;
```

定义：

```ts
closeThreatCount:
距离玩家小于近身危险距离的怪物数量。

preferredTargetIncluded:
当前稳定目标是否位于该挥击扇区内，是则为 1。

eliteTargetCount:
如果目前没有可靠的怪物威胁等级接口，第一版可以固定为 0，
但保留字段和扩展接口。

headingContinuityScore:
越接近上一击方向，奖励越高。

rotationCost:
转身角度越大，轻微扣分。
```

推荐参数：

```ts
const HIT_COUNT_WEIGHT = 10;
const CLOSE_THREAT_WEIGHT = 4;
const PREFERRED_TARGET_BONUS = 8;
const ELITE_TARGET_WEIGHT = 6;
const ROTATION_COST_WEIGHT = 1.5;
const HEADING_CONTINUITY_WEIGHT = 2;
```

注意：

```text
覆盖怪物数量必须是最高优先级。
转身成本只能作为轻微修正。
不得因为目标在背后而直接判定为非法。
```

## 6.4 评分结果锚点

最佳方向确定后，从该攻击扇区内选择一个锚点目标：

优先级：

```text
原稳定目标
→ 距离玩家最近的高威胁目标
→ 距离攻击方向中心线最近的目标
```

锚点用于目标稳定、UI 调试和释放条件。

# 七、第三阶段：目标稳定与释放规则

## 7.1 正确的释放条件

自动目标只能在以下情况释放：

```text
玩家松开普通攻击按钮；
目标死亡；
目标不可攻击；
目标离开释放半径；
武器被卸下；
玩家死亡；
技能明确中断普通攻击链。
```

删除以下规则：

```ts
weapon.shouldReleaseAutoTarget
```

不得因为 Recover 进度达到 50% 就释放目标。

如果必须保留该 getter，应改成只表示“朝向控制交还移动系统”，不能再控制目标生命周期。

目标所有权和身体朝向控制是两个独立概念。

## 7.2 释放半径

推荐：

```ts
const TARGET_RELEASE_RADIUS_SCALE = 1.4;
```

目标获取半径为：

```text
大锤攻击距离 + 自动瞄准补偿距离
```

目标释放半径为：

```text
获取半径 × 1.4
```

防止目标在边界附近反复获得和丢失。

## 7.3 切换迟滞

当前方向仍然有效时，不要因为新方向分数高一点就立即切换。

推荐：

```ts
const TARGET_SWITCH_SCORE_RATIO = 1.2;
```

只有新方案评分至少达到当前方案的 120%，才允许切换。

以下情况可以无视迟滞，立即切换：

```text
当前目标死亡；
当前方向预计命中数为 0；
当前目标离开释放半径；
当前方向没有任何存活怪物。
```


只有从未进行过有效攻击时，才允许使用人物当前朝向或移动方向作为回退。

# 十、第六阶段：动作阶段转向规则

## 10.1 首次攻击前摇

首次攻击允许 360°自动选择目标。

前摇阶段必须保证人物能够在锤头进入接触阶段之前大体转向目标。

不要固定只使用 540°/秒。

根据角度差动态计算最低所需转速：

```ts
function calculateRequiredWindupTurnSpeed(
  currentHeading: number,
  targetHeading: number,
  windupSeconds: number,
): number {
  const difference = Math.abs(shortestAngleDifference(
    currentHeading,
    targetHeading,
  ));

  const availableSeconds = Math.max(0.05, windupSeconds * 0.85);
  const requiredSpeed = difference / availableSeconds;

  return clamp(
    requiredSpeed,
    540 * DEG_TO_RAD,
    1080 * DEG_TO_RAD,
  );
}
```

产品目标：

```text
正后方目标可以被选择；
人物通过前摇快速转身；
不能瞬间传送式旋转；
进入接触阶段时朝向误差尽量小于 10°。
```

## 10.2 锤头接触阶段

接触阶段保持：

```ts
VanguardFacingPolicy.ContactLocked
```

最大修正速度建议：

```ts
120 * DEG_TO_RAD
```

接触阶段不得继续大幅追踪移动中的敌人。

锤子已经挥出去后，轨迹必须稳定。

## 10.3 连段下一击

每一段连击只在预输入窗口重新规划一次方向。

推荐转向限制：

```text
普通情况下：每段最多转向 100°
当前目标死亡：最多转向 160°
预计命中数为 0：允许重新选择整圆方向
```

不要使用当前固定 40°连段限制作为唯一规则。

40°会导致怪群已经移动到侧后方时，角色依然无法及时追击。

# 十五、必须增加的自动化测试

## 15.1 撤退攻击

```text
玩家向左下移动；
右上方存在范围内怪物；
请求普通攻击；
结果必须 targeted = true；
攻击方向必须指向右上怪物；
不能回退到左下移动方向。
```

## 15.2 正后方目标

```text
人物朝前；
正后方存在唯一怪物；
请求首次普通攻击；
必须选择该怪物；
不得因背后角度被过滤。
```

## 15.3 怪群覆盖优先

```text
方向 A 可命中 1 只近距离怪；
方向 B 可命中 4 只稍远怪；
系统必须选择方向 B。
```

## 15.4 精英权重

如果威胁权重接口已实现：

```text
方向 A 可命中 3 只普通怪；
方向 B 可命中 2 只普通怪和 1 只精英；
方向 B 的总评分更高时必须被选择。
```

## 15.5 持续攻击不因移动释放目标

```text
玩家按住攻击；
已锁定目标；
进入 Recover 后半；
玩家向目标反方向移动；
目标仍在释放半径；
目标不得被释放。
```

## 15.6 松开攻击释放目标

```text
玩家松开攻击；
下一帧必须释放 preferred target。
```

## 15.7 目标死亡后切换

```text
当前目标死亡；
侧后方存在怪群；
下一段连击允许重新规划；
必须切向新的高价值方向。
```

## 15.8 切换迟滞

```text
当前方向评分 40；
新方向评分 44；
不得切换。

当前方向评分 40；
新方向评分 52；
允许切换。
```

## 15.9 无目标回退

```text
存在最近战斗方向时，使用最近战斗方向；
没有战斗方向时，使用人物当前朝向；
不得优先使用当前移动方向。
```

## 15.10 移动与朝向解耦

```text
人物面向目标；
移动方向与目标相反；
世界位移必须沿移动输入；
身体朝向必须保持目标方向；
locomotionForward 必须为负数。
```

## 15.11 转身完成度

```text
目标位于正后方；
人物进入首次攻击前摇；
接触阶段开始时，
人物朝向与目标方向误差不超过约 10°。
```

# 十六、验收标准

场景：

```text
玩家向左下撤退；
右上方一大群怪物追击；
玩家持续按住普通攻击。
```

必须表现为：

1. 玩家继续向左下移动；
2. 人物身体逐渐朝向右上怪群；
3. 腿部播放自然后退或侧移动作；
4. 大锤选择能覆盖较多怪物的挥击方向；
5. 第一锤能够攻击右上怪群；
6. 按住攻击后稳定连续挥击；
7. 不因 Recover 后半释放目标；
8. 不因左摇杆方向改变而立刻切换攻击目标；
9. 原目标死亡后，在下一击预输入窗口重新选择怪群；
10. 锤头进入接触阶段后不得继续磁吸转弯。

体验验收语句：

```text
玩家应该感觉自己在一边撤退、一边用大锤控制怪群，
而不是感觉自己必须把摇杆推向怪物才能攻击。
```
