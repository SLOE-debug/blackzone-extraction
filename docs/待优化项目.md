# 归弦猎弓设计与实现方案

## 1. 文档概述

### 1.1 武器名称

**归弦猎弓**

暂定品质：史诗
武器类别：双手远程武器
核心关键词：

* 有限实体箭
* 自动锁敌
* 蓄力射击
* 箭矢附着
* 主动召回
* 回程伤害
* 战场布置
* ECS 行为组合

### 1.2 一句话定位

玩家永久持有少量不会消耗的实体箭矢。箭射出后会留在怪物或地面上，玩家通过继续攻击或主动技能将箭召回，召回路线本身也是攻击手段。

### 1.3 核心体验

归弦猎弓不采用传统弹药和换弹机制。

玩家需要思考的不是“还剩多少弹药”，而是：

* 当前有多少箭在手中；
* 箭被布置在战场的什么位置；
* 何时将箭召回；
* 从什么站位召回能穿过更多敌人；
* 应该把箭集中插在单个目标身上，还是分散到整个怪群；
* 是否保留部分箭作为后续技能锚点。

---

# 2. 设计目标

## 2.1 主要目标

### 避免无限箭矢的违和感

每支箭都是永久存在的实体。玩家射出一支箭，箭袋中就真实减少一支，不会凭空补充。

### 避免传统换弹和捡弹药

箭矢不需要拾取。箭全部射出后，继续攻击会自然进入召回流程，不打断战斗节奏。

### 形成区别于大锤的玩法

大锤主要围绕：

* 近距离攻击；
* 连段；
* 扫掠；
* 击退；
* 腾空；
* 怪群动量传播。

归弦猎弓主要围绕：

* 远距离布置；
* 投射物飞行；
* 单体附着；
* 空间路线；
* 延迟收益；
* 多实体协同。

### 最大限度利用 ECS

箭离开弓以后仍然长期存在于 ECS 世界中，可以拥有并动态增加不同状态：

* 飞行；
* 穿透；
* 附着；
* 元素；
* 召回；
* 分裂；
* 爆炸；
* 连线；
* 追踪。

不同效果由独立 System 处理，而不是为每种组合创建新的箭矢类。

---

## 2.2 非目标

第一阶段暂不实现：

* 传统弹药掉落；
* 手动捡箭；
* 复杂弹道下坠；
* 完整部位伤害；
* 大量箭矢同时存在；
* 每支箭独立创建 Cocos Node；
* 超过十种肉鸽模块；
* 复杂的箭矢物理刚体模拟。

第一版优先保证：

1. 射击手感清晰；
2. 召回过程可靠；
3. 去程和回程命中稳定；
4. ECS 数据结构能够继续扩展。

# 3. 基础资源规则

## 3.1 永久箭矢数量

玩家默认拥有 **6 支永久箭矢**。

这六支箭在整局游戏中不会被永久消耗，只会在以下状态之间转换：

```text
Ready
Drawing
Flying
EmbeddedInMonster
EmbeddedInWorld
Returning
```

建议状态定义：

```ts
export enum ArrowState {
  Ready,
  Drawing,
  Flying,
  EmbeddedInMonster,
  EmbeddedInWorld,
  Returning,
}
```

## 3.2 箭袋表现

玩家背部箭袋或角色周围应显示当前可用箭矢数量。

推荐优先使用世界内视觉反馈，而不是仅依靠数字 UI：

* 6 支箭：箭袋完整；
* 3 支箭：箭袋明显变空；
* 0 支箭：箭袋为空，攻击按钮呈现召回反馈；
* 箭开始返回：箭袋挂点出现对应的空位预览；
* 箭返回完成：实体箭重新显示在箭袋中。

## 3.3 箭矢不设置自然消失时间

插在地面或怪物身上的箭不会因超时自动消失。

只有以下行为会改变它们的状态：

* 玩家召回；
* 当前房间结束；
* 玩家死亡或重置；
* 武器被卸下；
* 特殊升级主动消耗箭矢；
* 系统发生异常时执行强制回收。

# 4. 基础攻击循环

## 4.1 攻击输入

归弦猎弓使用一个主攻击按钮。

### 点击攻击

快速射出一支箭。

适合：

* 连续清理普通怪物；
* 快速布置箭矢；
* 对近距离目标补刀。

### 按住攻击

进入蓄力。

蓄力期间：

* 角色降低移动速度；
* 弓弦逐渐拉满；
* 自动锁敌方向保持有限角度修正；
* 弹道预览逐渐稳定；
* 伤害、速度和穿透能力提高。

松开后发射。

## 4.2 无可用箭时的攻击行为

当 `Ready` 状态箭矢数量为零时，继续按住攻击按钮不会播放传统换弹。

系统选择最早离开箭袋的一支箭，开始自动召回。

召回完成后：

* 箭进入搭弦状态；
* 玩家仍然按住攻击时立即开始蓄力；
* 玩家已经松开攻击时，箭返回 `Ready`；
* 快速点击攻击时，可以采用短召回后立即快速射击。

完整循环：

```text
射出箭矢
→ 箭附着或落地
→ 六支箭全部离手
→ 继续攻击
→ 最早射出的箭自动返回
→ 返回途中伤害敌人
→ 自动搭弦
→ 再次射出
```

## 4.3 自动召回和主动召回的区别

### 自动召回

由普通攻击在无箭时触发。

特点：

* 每次只召回一支；
* 优先选择最早射出的箭；
* 保证持续攻击不会中断；
* 回程伤害较低；
* 不触发强力拔箭效果。

### 主动召回

由技能“万箭归弦”触发。

特点：

* 同时召回所有离手箭矢；
* 回程伤害更高；
* 触发拔箭伤害；
* 触发箭矢上的召回类模块；
* 可以作为主要爆发技能。

# 5. 瞄准与射击规则

## 5.1 自动锁敌

归弦猎弓沿用项目已有的怪群空间索引和目标评分思路，但远程目标选择应与大锤分开配置。

候选目标条件：

* 位于最大射程内；
* 未死亡；
* 不处于不可选取状态；
* 与玩家之间方向合法；
* 优先选择屏幕中心或角色朝向附近目标。

建议评分因素：

```text
目标距离
+ 朝向夹角
+ 目标体型
+ 目标威胁等级
+ 当前已附着箭矢数量
+ 目标切换惩罚
```

普通快速射击可以优先选择最近且稳定的目标。

满蓄力射击可以优先选择：

* 精英怪；
* 重型怪；
* 已插箭目标；
* 多个怪物排成直线时的后排目标。

## 5.2 发射方向

发射方向优先级：

1. 玩家明确瞄准方向；
2. 当前稳定锁定目标；
3. 玩家角色朝向；
4. 最近有效敌人方向。

## 5.3 弹道

第一版采用近似直线弹道。

暂不加入明显重力下坠，理由：

* 战斗节奏较快；
* 自动锁敌依赖稳定命中；
* 便于实现穿透和召回；
* 降低三维空间调试成本。

后续可以为特殊模块加入：

* 抛射箭；
* 曲射箭；
* 螺旋箭；
* 追踪箭。

# 6. 命中与附着规则

## 6.1 飞行检测

箭矢使用上一帧位置到当前帧位置的连续扫掠检测：

```text
previousPosition → currentPosition
```

不使用单帧点检测，避免高速箭矢穿过怪物。

建议碰撞形状：

* 小半径胶囊；
* 或线段加目标包围半径；
* 箭头位置作为权威命中位置。

## 6.2 命中怪物

普通箭命中怪物后：

1. 产生伤害事件；
2. 记录命中目标的 `populationId` 和 `entityId`；
3. 记录箭相对怪物中心的局部附着偏移；
4. 箭状态切换为 `EmbeddedInMonster`；
5. 箭随怪物位置、朝向和腾空高度更新。

建议第一版不追求真实骨骼附着，只使用：

```text
怪物世界位置
+ 随机或确定性的局部偏移
+ 当前怪物可视高度
```

## 6.3 命中地面

箭未命中怪物并达到最大射程时：

1. 在终点执行地面高度查询；
2. 将箭放置在地面；
3. 状态切换为 `EmbeddedInWorld`；
4. 保存世界坐标和朝向；
5. 成为后续召回和构阵技能的锚点。

## 6.4 穿透

基础快速射击不穿透。

满蓄力后获得一次基础穿透：

* 首个目标受到完整伤害；
* 第二个目标受到衰减伤害；
* 箭最终插在最后一个目标或地面。

命中过的目标通过当前攻击序列去重，避免同一支箭在同一次去程中重复命中同一怪物。

# 7. 主动技能

## 7.1 技能一：万箭归弦

### 技能描述

所有已经射出的箭同时脱离目标或地面，沿曲线返回玩家。箭矢拔出和回程穿透都会造成伤害。

### 激活条件

至少存在一支不处于 `Ready` 状态的箭。

### 执行流程

1. 为所有离手箭分配同一个召回技能序列；
2. 插在怪物身上的箭先触发拔箭伤害；
3. 所有箭切换为 `Returning`；
4. 箭根据当前位置向玩家弓手位置加速；
5. 回程过程中执行连续扫掠；
6. 每支箭对同一目标每次技能最多命中一次；
7. 箭到达玩家后恢复 `Ready`；
8. 所有箭返回后技能结束。

### 回程轨迹

不建议直接使用完全直线，否则多支箭容易重叠。

可以根据箭索引加入轻微曲线偏移：

```text
基础方向：箭位置 → 玩家
侧向偏移：箭索引对应的固定符号和幅度
末段收束：距离玩家越近，偏移越小
```

视觉效果应表现为多条轨迹从不同方向汇聚到玩家。

### 玩法价值

* 重新装填全部箭矢；
* 清理玩家与箭矢之间的怪群；
* 对插满箭的精英目标造成拔箭爆发；
* 鼓励玩家先布置箭矢，再改变站位召回；
* 形成攻击和资源恢复统一的技能。

---

## 7.2 技能二：猎场织网

### 技能描述

场上所有离手箭矢成为弦网锚点。相邻锚点之间生成弦线，怪物穿过弦线时受到伤害和短暂减速。

### 激活条件

至少存在两支处于以下状态的箭：

* `EmbeddedInMonster`
* `EmbeddedInWorld`

### 连接规则

第一版不生成全部两两连线，避免六支箭形成十五条线导致画面混乱。

推荐规则：

* 每支箭最多连接两条线；
* 优先连接最近的有效锚点；
* 保证连接关系尽量形成连续路径；
* 相同两支箭之间只能存在一条线；
* 总弦线数量不超过六条。

### 弦线命中

每帧或固定间隔检测：

```text
怪物上一帧位置 → 当前帧位置
```

是否与弦线线段发生交叉。

命中后：

* 造成一次切割伤害；
* 施加短暂减速；
* 写入弦线与目标的碰撞冷却；
* 冷却结束前不可重复触发同一条弦线。

### 动态锚点

箭插在怪物身上时，锚点随怪物移动。

因此可能出现：

* 怪物拖动弦线切过其他怪物；
* 被击退怪物带动整个弦网；
* 腾空怪物让弦线抬升；
* 多个被插箭怪物分散后扩大陷阱面积。

### 技能结束

推荐持续 5 秒。

结束时：

* 移除弦线；
* 箭仍停留在原位置；
* 玩家之后可以继续射箭或使用“万箭归弦”。

# 9. 肉鸽升级方向

第一版先实现少量模块，验证组合框架。

## 9.1 穿透箭头

效果：

* 所有箭额外获得一次穿透；
* 每次穿透后伤害衰减；
* 回程同样继承穿透次数。

适合验证：

* 去程与回程共享行为组件；
* 命中去重；
* 多目标事件生成。

## 9.2 爆裂箭头

效果：

* 箭从怪物身上拔出时产生范围爆炸；
* 地面箭进入召回状态时也产生较小爆炸。

与万箭归弦组合后形成集中爆发。

## 9.3 导电箭头

效果：

* 插箭目标受到其他箭命中时，附近插箭目标受到连锁伤害；
* 弦线命中可以释放短距离电弧。

## 9.4 猎钩箭头

效果：

* 召回箭命中怪物时，对怪物施加朝玩家方向的轻微拖拽；
* 重型怪物只受到较弱位移；
* 不应覆盖现有击退，而应使用向量累积模式。

## 9.5 分裂箭头

效果：

* 满蓄力首次命中时产生两支临时子箭；
* 子箭不能附着；
* 子箭不占用永久箭矢数量；
* 子箭可以继承部分行为标记。

第一版模块数量控制在四到五种，避免在核心射击和召回尚未稳定时过早扩张。

# 10. ECS 数据设计

## 10.1 箭矢采用固定容量 SoA

箭矢不使用每发创建和销毁的对象模型。

建议建立：

```ts
class BattlefieldArrowPopulation {
  readonly active: Uint8Array;
  readonly state: Uint8Array;
  readonly ownerEntityId: Uint32Array;
  readonly arrowSlot: Uint8Array;

  readonly positionX: Float32Array;
  readonly positionY: Float32Array;
  readonly positionZ: Float32Array;

  readonly previousX: Float32Array;
  readonly previousY: Float32Array;
  readonly previousZ: Float32Array;

  readonly velocityX: Float32Array;
  readonly velocityY: Float32Array;
  readonly velocityZ: Float32Array;

  readonly directionX: Float32Array;
  readonly directionY: Float32Array;
  readonly directionZ: Float32Array;

  readonly damage: Float32Array;
  readonly speed: Float32Array;
  readonly remainingRange: Float32Array;
  readonly pierceRemaining: Uint8Array;

  readonly attachedPopulationId: Uint32Array;
  readonly attachedEntityId: Uint32Array;
  readonly attachmentOffsetX: Float32Array;
  readonly attachmentOffsetY: Float32Array;
  readonly attachmentOffsetZ: Float32Array;

  readonly attackSequenceId: Uint32Array;
  readonly skillSequenceId: Uint32Array;
  readonly moduleMask: Uint32Array;
}
```

## 10.2 箭矢容量

单人游戏第一版容量可以固定为：

```text
永久箭：6
临时子箭预留：18
总容量：24
```

未来支持多人时，可按最大玩家数预分配。

## 10.3 箭矢模块

第一版可以使用位标记：

```ts
export enum ArrowModuleFlag {
  Piercing = 1 << 0,
  Explosive = 1 << 1,
  Conductive = 1 << 2,
  Grappling = 1 << 3,
  Splitting = 1 << 4,
}
```

简单模块通过 `moduleMask` 查询。

需要独立计时或参数的模块再增加对应 SoA 数据：

```text
explosionRadius
chainRange
recallPullStrength
splitCount
```

# 11. System 划分

建议按以下顺序更新。

## 11.1 BowInputSystem

职责：

* 读取攻击和技能输入；
* 解析点击、按住和松开；
* 写入武器命令；
* 不直接创建箭或造成伤害。

## 11.2 BowActionSystem

职责：

* 管理空闲、蓄力、释放和恢复；
* 决定攻击是否成功；
* 选择可用箭；
* 无可用箭时请求自动召回；
* 生成发射命令。

## 11.3 ArrowLaunchSystem

职责：

* 将 `Ready` 箭切换为 `Flying`；
* 初始化位置、方向、速度和伤害；
* 分配攻击序列；
* 写入渲染脏标记。

## 11.4 ArrowFlightSystem

职责：

* 推进飞行位置；
* 保存上一帧位置；
* 处理最大射程；
* 生成投射物扫掠查询；
* 不直接造成伤害。

## 11.5 ArrowCollisionSystem

职责：

* 使用怪群空间索引收集候选目标；
* 执行连续线段或胶囊检测；
* 处理命中顺序；
* 写入伤害事件；
* 决定穿透或附着；
* 对同一攻击序列去重。

## 11.6 ArrowAttachmentSystem

职责：

* 更新插在怪物身上的箭矢位置；
* 处理怪物移动、腾空和死亡；
* 怪物死亡后将箭转换为地面附着或等待召回；
* 目标实体无效时执行安全降级。

## 11.7 ArrowRecallSystem

职责：

* 处理自动召回和主动召回；
* 计算返回轨迹；
* 执行回程扫掠；
* 写入回程伤害和拖拽事件；
* 到达玩家后恢复箭矢状态。

## 11.8 ArrowTetherSystem

职责：

* 创建和维护弦线连接；
* 更新动态锚点；
* 检测怪物是否穿过弦线；
* 生成伤害和状态事件；
* 维护目标碰撞冷却。

## 11.9 ArrowModuleSystems

按模块拆分：

```text
PiercingArrowSystem
ExplosiveArrowSystem
ConductiveArrowSystem
GrapplingArrowSystem
SplittingArrowSystem
```

各 System 只查询拥有对应标记的箭或事件。

## 11.10 ArrowRenderSystem

职责：

* 批量渲染箭矢；
* 根据箭状态计算变换；

* 弦线使用固定容量动态线段缓冲。

# 12. 通用战斗事件改造

## 12.1 当前问题

第二把武器接入后，不应继续向“大锤命中类型”中追加弓箭事件。

不推荐：

```ts
enum BattlefieldWeaponHitKind {
  Swing,
  Uppercut,
  GroundSlam,
  SpinPulse,
  SpinFinal,
  ArrowImpact,
  ArrowRecall,
  ArrowExplosion,
}
```

这种方式会让所有武器共用一个不断扩张的招式枚举。

## 12.2 推荐事件缓冲

拆分为通用效果事件：

```text
DamageEventBuffer
KnockbackEventBuffer
LaunchEventBuffer
StatusApplyEventBuffer
ExplosionEventBuffer
ProjectileSpawnCommandBuffer
```

### DamageEventBuffer 建议字段

```text
sourceEntityId
sourceWeaponId
attackSequenceId
targetPopulationId
targetEntityId
damage
damageKind
hitPositionX
hitPositionY
hitPositionZ
```

### KnockbackEventBuffer 建议字段

```text
targetPopulationId
targetEntityId
directionX
directionZ
initialSpeed
duration
maximumSpeed
combineMode
```

弓和大锤都只负责生成事件。

统一效果系统负责：

* 验证目标；
* 计算抗性；
* 应用伤害；
* 应用击退；
* 应用腾空；
* 记录性能统计。

# 13. 装备定义改造

## 13.1 武器定义判别联合

建议新增：

```ts
export enum WeaponKind {
  Sledgehammer = 'sledgehammer',
  ReturningBow = 'returning-bow',
}
```

定义公共基础：

```ts
interface WeaponDefinitionBase<TId extends string> {
  readonly id: TId;
  readonly kind: WeaponKind;
  readonly baseDamage: number;
  readonly attackIntervalSeconds: number;
}
```

近战定义：

```ts
interface MeleeWeaponDefinition<TId extends string>
extends WeaponDefinitionBase<TId> {
  readonly reach: number;
  readonly hitArcRadians: number;
  readonly knockbackImpulse: number;
}
```

投射物定义：

```ts
interface ProjectileWeaponDefinition<TId extends string>
extends WeaponDefinitionBase<TId> {
  readonly projectileSpeed: number;
  readonly projectileRadius: number;
  readonly maximumRange: number;
  readonly chargeDurationSeconds: number;
  readonly maximumChargeDamageScale: number;
  readonly projectileCapacity: number;
  readonly recallSpeed: number;
}
```

## 13.2 持握配置

不再在公共持握配置中直接使用：

```text
hammerHeadLocalPosition
hammerHeadRadius
```

建议改为语义化挂点：

```ts
interface HeldEquipmentProfile {
  readonly grip: WeaponGrip;
  readonly heldScale: number;
  readonly attachmentPoints: Readonly<{
    mainGrip: LocalPoint;
    supportGrip: LocalPoint;
    projectileOrigin?: LocalPoint;
    drawHandTarget?: LocalPoint;
    impactHead?: LocalPoint;
  }>;
}
```

大锤读取 `impactHead`。

弓读取：

* `mainGrip`
* `supportGrip`
* `projectileOrigin`
* `drawHandTarget`

# 14. 动画与角色控制

## 14.1 武器动作不要继续使用全局大枚举

建议将公共动作保持精简：

```text
Idle
Primary
Skill
Recover
```

具体阶段由武器自己的 ActionState 管理。

归弦猎弓内部动作：

```ts
enum BowAction {
  Idle,
  QuickDraw,
  Charging,
  Release,
  Recover,
  AutoRecalling,
  SkillRecalling,
  TetherCast,
}
```

## 14.2 蓄力表现

蓄力时：

* 主手稳定弓身；
* 副手向后移动；
* 弓弦中心跟随副手；
* 身体轻微侧转；
* 蓄力比例驱动弓臂弯曲或弦线形变；
* 满蓄力出现明确音效和视觉闪烁。

## 14.3 移动控制

建议：

* 快速射击恢复阶段移动倍率：0.85；
* 蓄力移动倍率：0.55；
* 万箭归弦释放期间移动倍率：0.7；
* 猎场织网释放期间短暂定向锁定；
* 召回箭飞行期间不限制玩家移动。

# 15. 边界情况

## 15.1 怪物死亡

插箭怪物死亡时：

* 箭不立即销毁；
* 优先落到怪物死亡位置附近地面；
* 保留原来的箭索引和模块；
* 若正在主动召回，则直接继续返回。

## 15.2 怪物被移除

如果目标实体已从 Population 中移除：

* 清除附着关系；
* 使用最后已知位置；
* 转换为地面箭；
* 禁止读取失效实体数组。

## 15.3 箭离开地图

检测到箭位置非法、超出战场边界或出现非有限数值时：

* 取消当前状态；
* 强制切换为 `Returning`；
* 无法正常返回时直接恢复 `Ready`；
* 记录调试警告和恢复次数。

## 15.4 玩家切换武器

切换离开弓时：

* 所有箭停止造成伤害；
* 所有箭快速返回；
* 返回完成前不允许箭矢残留为攻击实体；
* 可以隐藏回收过程，但数据必须恢复；
* 再次装备时保证六支箭全部可用。

## 15.5 玩家死亡

玩家死亡时：

* 停止新的箭矢事件；
* 清除弦线；
* 所有永久箭重置；
* 所有临时箭销毁；
* 清空攻击序列和目标去重状态。

# 16. 性能要求

## 16.1 禁止项

* 禁止每支箭每帧创建临时数组；
* 禁止为每支箭创建独立 Update；
* 禁止每帧扫描全部怪物；
* 禁止弦线之间进行无界两两组合；
* 禁止命中时创建大量短生命周期对象；
* 禁止频繁创建和销毁 Cocos Node。

## 16.2 推荐策略

* 箭矢固定容量 SoA；
* 命中事件固定容量缓冲；
* 复用怪群宽相位空间索引；
* 连续扫掠只查询箭矢路径附近候选目标；
* 附着箭直接读取目标 Population 数据；
* 弦线固定最大数量；
* 渲染采用批量变换上传；
* 只上传变化的箭矢槽位；
* 技能命中去重使用序列号或固定容量表。

## 16.3 性能验收

在目标怪物数量下：

* 六支永久箭同时飞行无明显帧时间尖峰；
* 万箭归弦同时返回时不产生显著 GC；
* 六条弦线持续检测时帧时间稳定；
* 高频快速射击不产生对象数量持续增长；
* 反复装备、卸下和重置后无箭矢实体泄漏。

## 17.1 单元测试

# 19. MVP 验收标准

第一版可以对外试玩前，至少满足：

1. 玩家拥有六支永久箭；
2. 箭射出后不会凭空恢复；
3. 箭能插在怪物或地面上；
4. 箭全部射出后，继续攻击会自动召回一支；
5. 召回箭能在回程中造成伤害；
6. 返回箭能与下一次射击自然衔接；
7. 主动技能可以同时召回全部箭；
8. 所有箭状态由固定容量数据管理；
9. 不为每支箭创建独立 Update；
10. 大锤原有战斗功能和测试无回归。

# 20. 最终设计结论

归弦猎弓的核心不是“拥有无限弹药的弓”，而是“拥有六支永久战斗实体的武器”。

箭矢同时承担四种作用：

* 当前攻击的投射物；
* 留在战场上的资源；
* 未来召回攻击的起点；
* 技能和肉鸽模块的行为载体。

普通射击负责布置，走位负责调整路线，召回负责收割和恢复资源，猎场织网负责利用箭矢之间的空间关系。

它与大锤形成清晰互补：

```text
大锤：通过身体和武器直接改变怪群状态
归弦猎弓：通过持续存在的箭矢利用怪群状态
```

这把武器也将作为项目从“大锤专用战斗结构”升级到“通用、可组合武器 ECS”的第一块验证内容。
