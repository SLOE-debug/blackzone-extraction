正确修法是把“猎场织网”明确成**地面投影陷阱**：

* 箭矢只提供激光两端的 `X/Z`。
* 激光的 `Y` 固定在地面上方。
* 插在怪物身体上的箭仍随怪物移动，但只拖动激光的平面端点，不把整条激光抬到空中。

现在的问题正是碰撞和渲染都使用了两支箭各自的真实 `Y`，因此怪物身上的高位箭会把激光拉成三维斜线。

## 1. 修改弦网配置

文件：

```text
assets/bundles/battlefield/equipment/projectile/model/
battlefield-tether-config.ts
```

改为：

```ts
/** 猎场弦网固定在地面上方的高度。 */
export const BATTLEFIELD_TETHER_GROUND_HEIGHT = 0.16;

/** 弦线碰撞的平面半径。 */
export const BATTLEFIELD_TETHER_COLLISION_RADIUS = 0.18;
```

原来的：

```ts

```

最好删除或重命名，避免继续被理解成“基于箭矢 Y 的额外偏移”。

### 修改 `resolveCollisions()`

```ts
private resolveCollisions(
  arrows: BattlefieldArrowPopulation,
  target: BattlefieldArrowCombatTarget,
  events: BattlefieldDamageEventBuffer,
  baseDamage: number,
  damageScale: number,
  hitCooldownSeconds: number,
  slowScale: number,
  slowDurationSeconds: number,
  groundY: number,
): void {
  const tetherY = groundY + BATTLEFIELD_TETHER_GROUND_HEIGHT;

  for (let edge = 0; edge < this.tetherCountValue; edge++) {
    const start = this.startArrowIndex[edge] ?? 0;
    const end = this.endArrowIndex[edge] ?? 0;

    if (
      !isAnchor(arrows.state[start] as BattlefieldArrowState)
      || !isAnchor(arrows.state[end] as BattlefieldArrowState)
    ) {
      continue;
    }

    // 箭只贡献 XZ；Y 固定在地面平面。
    this.query.startX = arrows.positionX[start] ?? 0;
    this.query.startY = tetherY;
    this.query.startZ = arrows.positionZ[start] ?? 0;

    this.query.endX = arrows.positionX[end] ?? 0;
    this.query.endY = tetherY;
    this.query.endZ = arrows.positionZ[end] ?? 0;

    target.collectTetherOverlapHits(this.query, this.hits);

    for (let hit = 0; hit < this.hits.count; hit++) {
      const populationId = this.hits.populationId[hit] ?? 0;
      const entityId = this.hits.entityId[hit] ?? 0;

      if (!this.acceptCooldown(
        edge,
        populationId,
        entityId,
        hitCooldownSeconds,
      )) {
        continue;
      }

      events.append({
        sourceEntityId: arrows.ownerEntityId[start] ?? 0,
        sourceWeaponId: BattlefieldWeaponSourceId.ReturningBow,
        attackSequenceId: this.skillSequenceId,
        targetPopulationId: populationId,
        targetEntityId: entityId,
        damage: baseDamage * damageScale,
        damageKind: BattlefieldDamageKind.Tether,
        hitPositionX: this.hits.x[hit] ?? 0,
        hitPositionY: tetherY,
        hitPositionZ: this.hits.z[hit] ?? 0,
      });

      target.applyArrowSlow(
        populationId,
        entityId,
        slowScale,
        slowDurationSeconds,
      );
    }
  }
}
```

当前代码遍历了全部命中并按 `edge + populationId + entityId` 单独冷却，因此不需要修改冷却机制。

## 4. Renderer 也必须使用相同地面 Y

现在 Renderer 会把两支箭各自的真实 Y 传给 `writeBattlefieldTether()`，而几何内部再加偏移，所以视觉仍然是一根三维斜线。

修改：

```text
battlefield-arrow-renderer.ts
```

在弦线循环之前：

```ts
const tetherY = ownerY + BATTLEFIELD_TETHER_GROUND_HEIGHT;
```

将：

```ts
const startY = arrows.positionY[start] ?? ownerY;
const endY = arrows.positionY[end] ?? ownerY;
```

改为：

```ts
const startY = tetherY;
const endY = tetherY;
```

完整逻辑：

```ts
const tetherY = ownerY + BATTLEFIELD_TETHER_GROUND_HEIGHT;

for (let edge = 0; edge < BATTLEFIELD_MAXIMUM_TETHER_COUNT; edge++) {
  const active = tethers.active && edge < tethers.tetherCount;
  const start = tethers.startArrowIndex[edge] ?? 0;
  const end = tethers.endArrowIndex[edge] ?? 0;

  const startX = arrows.positionX[start] ?? ownerX;
  const startZ = arrows.positionZ[start] ?? ownerZ;
  const endX = arrows.positionX[end] ?? ownerX;
  const endZ = arrows.positionZ[end] ?? ownerZ;

  writeBattlefieldTether(
    this.geometry,
    edge,
    startX,
    tetherY,
    startZ,
    endX,
    tetherY,
    endZ,
    active,
    calculateTetherHalfWidth(
      (startX + endX) * 0.5,
      (startZ + endZ) * 0.5,
      ownerX,
      ownerZ,
    ),
  );
}
```

## 5. 几何函数不要再次抬高

修改：

```text
battlefield-arrow-batch-geometry.ts
```

目前里面还有：

```ts
const raisedStartY = startY + BATTLEFIELD_TETHER_HEIGHT_OFFSET;
const raisedEndY = endY + BATTLEFIELD_TETHER_HEIGHT_OFFSET;
```

改为直接使用传入的 Y：

```ts
const raisedStartY = startY;
const raisedEndY = endY;
```

或者直接删除临时变量：

```ts
writeQuadXYZ(
  geometry,
  first,
  startX + sideX, startY, startZ + sideZ,
  startX - sideX, startY, startZ - sideZ,
  endX - sideX, endY, endZ - sideZ,
  endX + sideX, endY, endZ + sideZ,
  0.3, 0.88, 0.92,
);
```

否则会出现：

```text
系统固定到地面 + 0.16
几何又额外 + 0.06
```

导致视觉和碰撞再次错开。

## 6. 怪物身上的箭增加一根视觉引线

否则玩家会看到箭悬在怪物身上，但地面激光从它脚下开始，两者似乎没有连接。

可以增加一根**只负责表现、不造成伤害**的竖直线：

```text
怪物身上的箭
       │
       │ 视觉引线
       │
═══════╪═══════ 地面伤害线
```

引线端点：

```ts
const arrowY = arrows.positionY[index] ?? tetherY;
const minimumY = Math.min(arrowY, tetherY);
const maximumY = Math.max(arrowY, tetherY);
```

这部分可以放到第二个提交，核心碰撞修复不必等它。

## 最终效果

修改前：

```text
箭 A 的 Y ──────────┐
                    ╲
                     ╲ 三维斜线
                      ╲
地面箭 B ─────────────┘
```

修改后：

```text
箭 A 的 XZ ─────────┐
                    │
地面伤害平面 ═══════╪════════ 箭 B 的 XZ
```

怪物只要：

* XZ 占位与线段重叠；
* 脚底没有明显腾空；

就会受到伤害。
