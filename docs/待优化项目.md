## 更直接的证据

当前碰撞使用的是箭矢端点原始高度，但渲染时激光额外抬高了：

```ts
const raisedStartY = startY + 0.06;
const raisedEndY = endY + 0.06;
```

因此截图中的：

```text
碰撞激光Y = 0.232
```

玩家实际看到的大约是：

```text
视觉激光Y = 0.232 + 0.06 = 0.292
```

而身体判定范围是：

```text
0.243 ～ 1.008
```

所以：

```text
碰撞激光：0.232，失败
视觉激光：0.292，成功
```

也就是**画面看起来穿过怪物身体，但实际碰撞线在画面线下方 6 厘米**。

# 应该怎么改

## 第一处：统一视觉和碰撞高度

不要只在 Renderer 里偷偷加 `0.06`。

建立共享常量：

```ts
export const BATTLEFIELD_TETHER_HEIGHT_OFFSET = 0.06;
```

弦网查询时也使用相同高度：

```ts
this.query.startY =
  (arrows.positionY[start] ?? 0)
  + BATTLEFIELD_TETHER_HEIGHT_OFFSET;

this.query.endY =
  (arrows.positionY[end] ?? 0)
  + BATTLEFIELD_TETHER_HEIGHT_OFFSET;
```

Renderer 也使用同一个常量：

```ts
const raisedStartY =
  startY + BATTLEFIELD_TETHER_HEIGHT_OFFSET;

const raisedEndY =
  endY + BATTLEFIELD_TETHER_HEIGHT_OFFSET;
```

这样至少能保证：

> 玩家看到的线，就是实际造成伤害的线。

仅这一项就会让截图中的这个怪物从拒绝变为命中。

---

## 第二处：地面弦网不应该只检测“躯干胶囊”

更根本的问题是，弦网是地面陷阱，怪物腿或脚踩在线上也应该受伤。

当前高度范围是：

```ts
centerY - expandedHalfHeight
centerY + expandedHalfHeight
```

它仍然更接近“躯干范围”。

建议弦网专门使用：

```ts
const footY =
  BATTLEFIELD_MONSTER_SPAWN.groundOffsetY
  + (crowd.elevation[entityId] ?? 0) * scale;

const bodyTopY =
  centerY
  + (crowd.halfHeight[entityId] ?? 0) * scale;

const minimumY = footY - query.radius;
const maximumY = bodyTopY + query.radius;
```

然后：

```ts
const lineY =
  query.startY
  + (query.endY - query.startY) * progress;

if (lineY < minimumY || lineY > maximumY) {
  continue;
}
```

这样语义就是：

```text
怪物脚底到身体顶部
```

而不是：

```text
只判断怪物躯干中心附近
```

## 推荐最终结构

把当前辅助函数：

```ts
findTetherVerticalCapsuleOverlapProgress(
  ...,
  centerY,
  halfHeight,
  contactRadius,
)
```

改成显式范围：

```ts
findTetherVerticalRangeOverlapProgress(
  startX,
  startY,
  startZ,
  endX,
  endY,
  endZ,
  centerX,
  centerZ,
  minimumY,
  maximumY,
  contactRadius,
)
```

因为弦网本来就不需要严格复用“箭矢撞身体胶囊”的语义。
